Handshake Logic

Wire.beginTransmission(address);
byte error = Wire.endTransmission();

if (error == 0) {
  // ACK — device present
} else if (error == 4) {
  // Bus error
}
Why it works: The sketch loops 0x01 → 0x7E, sending a zero-byte transmission. If a device ACKs, Wire.endTransmission() returns 0. UI resolves names from a 25-entry table.
